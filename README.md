# GrafoJava

Projeto acadêmico desenvolvido em **Java** para representar e manipular **grafos direcionados e ponderados** por meio de uma **matriz de adjacência**, utilizando um menu no terminal.

## Funcionalidades

- Criar uma matriz de adjacência com a quantidade de vértices informada.
- Visualizar a matriz no terminal.
- Inserir ou atualizar os pesos das conexões entre vértices.
- Consultar o menor peso cadastrado *(funcionalidade com erro conhecido; veja abaixo)*.

**Representação:** `0` indica ausência de ligação; valores positivos representam os pesos das conexões. O programa não permite ligações de um vértice para ele mesmo.

## Tecnologias

- Java (JDK 9 ou superior)
- Programação orientada a objetos
- Matrizes bidimensionais
- Sem dependências externas

## Objetivo

Praticar **Java**, **estrutura de dados**, **matrizes de adjacência** e conceitos básicos de **teoria dos grafos**.
